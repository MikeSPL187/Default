# Metrolist Watch

Клиент YouTube Music для Android с экспортом музыки на часы Huawei

</div>

## Что есть в этой версии

**Экспорт на часы Huawei**
- Экспорт трека, плейлиста или всей скачанной музыки в папку `Music/Metrolist Watch` в формате AAC, который понимают часы
- Автоэкспорт новых загрузок
- Отметка у уже экспортированных треков

**Загрузки и офлайн**
- Загрузка только по Wi‑Fi
- Обложки сохраняются вместе с треками и видны без интернета
- Без сети плеер пропускает недоступные треки, а «Понравившиеся» показывают только скачанное
- Фильтр «Скачанные» в альбомах

**Воспроизведение**
- Предзагрузка следующего трека
- Порядок перемешивания сохраняется после перезапуска
- Длинные треки (подкасты, миксы от 20 минут) продолжаются с места остановки
- Очередь надёжно восстанавливается после перезапуска

**Прочее**
- Приоритет синхронизированных текстов песен, сдвиг текста до ±30 с
- Удаление дубликатов из плейлиста
- Статистика «ваши прослушивания» в информации о треке
- Ссылки для «Поделиться» на YouTube вместо YouTube Music (по желанию)
- Исправления ошибок: автовозобновление после паузы, лишние «похожие» треки в конце плейлиста, фильтр откровенного контента, синхронизация плейлистов и другие

## Скачать

APK собирается автоматически: вкладка **Actions** → последняя успешная сборка → артефакт `metrolist-watch-foss-release`.

Нужен Android 8.0 или новее.
